# Passphrase word list

`eff_large_wordlist.txt` is the Electronic Frontier Foundation's 7,776-word
Diceware list, distributed under the Creative Commons Attribution 4.0
International license (CC BY 4.0). It is bundled locally so passphrase generation
works without a network request.

Source: [EFF Diceware](https://www.eff.org/dice), original file:
https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt

Attribution: Electronic Frontier Foundation, “EFF's Long Wordlist,” 2016.
The list is used unchanged. A uniform selection from all 7,776 entries provides
`log2(7776)` bits of entropy per generated word. This estimate applies only to
the generator's independent cryptographic selections, not to words chosen or
edited by a person.
